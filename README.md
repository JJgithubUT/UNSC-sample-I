# UNSC Design System (React + Vite)

```bash
npm install
npm run dev-5199
```

- `src/styles/tokens.css`: tokens (color, tipografía, easing, bisel).
- `src/styles/components.css`: estilos de componentes y animaciones.
- `src/components/`: Button, Panel, StatusChip, AlertCard, ShieldBar, HealthBar, CircularProgress, Radar.
- `src/App.jsx`: página de muestra interactiva.

Se Respeta `prefers-reduced-motion`. No incluye assets oficiales de Halo.
